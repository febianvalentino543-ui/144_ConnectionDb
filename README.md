Project ini merupakan implementasi **Express JS** yang terhubung dengan database **PostgreSQL** menggunakan library `pg`.

## Fitur
- Membuat koneksi Express JS dengan PostgreSQL.
- Menggunakan database `mahasiswa`.
- Mengambil data dari tabel `biodata`.
- Menampilkan data menggunakan method **GET**.
- Data dapat diuji melalui browser atau Postman.

## Struktur Database
Database:
`mahasiswa`

Tabel:
`biodata`

Kolom:
- `id` – Primary Key
- `nama`
- `nim`
- `kelas`
